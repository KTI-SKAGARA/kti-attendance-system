# KTI SKAGARA — Sistem Absensi & Kas Rutin

Aplikasi Web Full-Stack berbasis **Next.js (App Router)**, **TypeScript**, dan **Tailwind CSS** untuk manajemen absensi dan kas rutin organisasi **KTI SMK Negeri 3 Jepara (SKAGARA)**.

---

## Fitur Utama
1. **Dashboard & Analisis Statistik**
2. **Input Absensi** (Normal & Mode Cepat/Checklist)
3. **Manajemen Angkatan** (Admin Panel)
4. **Export CSV per Angkatan per Bulan**
5. **Autentikasi Admin** (Protected Routes)

---

## Jalankan Lokal

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).
